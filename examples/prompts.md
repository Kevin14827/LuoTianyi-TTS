# 示例文本

## 中文

```
你好呀，我是洛天依。好久没跟你说话了，今天想听我说点什么？
```

```
刚刚演唱的这些歌曲，大家都喜欢吗？
```

```
今天天气真好，要不要一起出去走走？我请你吃小笼包。
```

```
夜深了，早点休息吧。明天还要早起呢。
```

## 日文

```
こんにちは、ルォ・ティエンイーです。今日もよろしくお願いします。
```

```
一緒に歌いましょうか？
```

## 英文

```
Hello, this is Luo Tianyi. Nice to meet you.
```

```
Thank you for listening. See you next time.
```

## 标点建议

- 用 `，` `。` `？` `！` 自然断句，`cut5` 会据此切分
- 单句控制在 20 字以内，长句容易尾音不稳
- 避免连续感叹号、省略号堆叠
