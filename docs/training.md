# 训练记录

## 素材

| 项 | 值 |
|---|---|
| 来源 | 现场演出录音 |
| 处理 | 重切为 30 段 |
| 单段时长 | 3–10 秒 |
| 总时长 | 221.6 秒 |
| 采样率 | 32 kHz |

标注：每段人工听写文字，日语名统一写片假名 `ルォ・ティエンイー`。

## 训练配置

基座 GPT-SoVITS v2Pro。

| 阶段 | epoch | 产物 |
|---|---|---|
| SoVITS（声学） | 8 | `tianyi2_e8_s128.pth` |
| GPT（语义） | 15 | `tianyi2-e15.ckpt` |

## 试过的弯路

**去混响**：素材是现场扩声录音，自带厅堂混响。试过 UVR5 的两条分离路线，都把音色本身削掉了，得不偿失，最终保留原始混响。这也是输出带一点厅堂感的来源。

**加 epoch**：SoVITS 超过 8 epoch 后过拟合明显，长句尾音开始飘，回退到 8。

## 复现说明

原始素材不随仓库分发，因此本仓库**不提供端到端复现路径**。上面的配置仅作记录，供已有素材的人参考。
